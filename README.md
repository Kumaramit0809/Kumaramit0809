### 📌 Featured Projects

#### [StagePass](https://github.com/Kumaramit0809/stagePass)
*React.js · Node.js · MySQL · Tailwind CSS*

A full-stack event booking platform with event discovery, interactive seat selection, and secure checkout. Includes email/password and Google OAuth login (JWT-based), an admin panel for managing events, users, and orders, and a real-time seat-holding system with a 10-minute lock to prevent double-booking.

#### [FinTrack](https://github.com/Kumaramit0809/personal-finance-tracker)
*React.js · Node.js · MySQL · Tailwind CSS*

A full-stack personal finance management app for tracking expenses, income, and budgets. Built with JWT-based authentication, protected routes, password reset, and a MySQL + REST API backend for secure storage of financial data, with responsive dashboards on the frontend.

#### [Movieflexia](https://github.com/Kumaramit0809/movie-watchlist)
*React.js · Tailwind CSS · OMDb API*

A movie discovery app that lets users search for movies in real time using the OMDb API and save them to a personal watchlist stored in localStorage, so it persists across sessions.
